Use this **printable Dubai relocation checklist** for documents, visa, housing, utilities, banking, schools, and family setup. Order matters: **Ejari before DEWA**, medical before Emirates ID, schools before long lease if children need seats.

> **Disclaimer:** July 2026 checklist. Confirm current rules with your PRO, landlord, and school.

## What should you complete 8 to 12 weeks before arrival?

**Documents and attestation**

| Task | Done |
| --- | --- |
| Passport validity 6+ months | ☐ |

| Marriage and birth certificates attested (families) | ☐ |
| Employment contract signed | ☐ |
| Passport photos (UAE spec) | ☐ |

**Employer / PRO**

| Task | Done |
| --- | --- |
| Submit documents for entry permit | ☐ |
| Confirm who pays visa, medical, EID fees | ☐ |
| Written PRO timeline (days, not "soon") | ☐ |
| Family visa timing agreed | ☐ |
| Health insurance policy received | ☐ |

**Housing research (do not sign lease yet)**

| Task | Done |
| --- | --- |
| Pin office on map | ☐ |
| Shortlist 3 communities | ☐ |

| Check RERA rent calculator for area | ☐ |
| Compare [Sharjah commuter guide](/guides/sharjah-dubai-commuter-guide/) if budget tight | ☐ |
| Line up RERA-registered viewing agents | ☐ |

**Schools (families)**

| Task | Done |
| --- | --- |
| Email 3 schools: year group, start date, waiting list | ☐ |
| Fee structure and bus routes received | ☐ |
| Pay assessment fees if required | ☐ |
| Read [school fees vs property budget](/guides/school-fees-vs-property-budget-dubai/) | ☐ |

**Financial prep**

| Task | Done |
| --- | --- |
| Notify home bank of UAE move | ☐ |
| Budget upfront cash (singles AED 15 to 25K, families AED 40 to 70K) | ☐ |
| Multi-currency card ordered | ☐ |
| FX plan if buying property: [currency transfer UAE](/guides/currency-transfer-buy-property-uae/) | ☐ |

## What are common failure points?

| Failure | Fix |
| --- | --- |
| DEWA before Ejari | Register Ejari first |
| Bank without Ejari or EID | Wait for tenancy + ID |
| School seat lost | Apply before 12-month lease |
| Cheque count surprise | Negotiate 1 vs 4 cheques upfront |
| Driving on tourist licence too long | Check RTA nationality rules |

**Rent cheques:** 1 cheque often discounts rent; 4 cheques eases cash flow. **Temporary housing:** budget AED 300 to 800/night for 2 to 4 weeks. **Shipping:** send container 6 to 8 weeks before needed.

## What banking steps follow visa stamping?

| Task | Done |
| --- | --- |
| Book bank appointment (salary certificate or investor docs) | ☐ |
| Bring stamped passport, EID, Ejari, salary slip or title deed | ☐ |
| Order cheque book if paying rent by cheque | ☐ |
| Set up mobile banking and beneficiary limits | ☐ |
| Link multi-currency account if receiving overseas income | ☐ |

Most banks want **Ejari plus Emirates ID**; property owners may use title deed instead of lease. Allow **1 to 2 weeks** after stamping for account activation.

## What should pet owners add to the checklist?

| Task | Done |
| --- | --- |
| Import permit and vaccination record | ☐ |
| Landlord pet clause in tenancy | ☐ |
| Register with municipality if required | ☐ |
| Vet clinic selected near home | ☐ |

Pet import lead times can exceed **30 days**; start before shipping household goods.

## How do remote workers and freelancers differ?

Skip employer PRO blocks; add **freelance or green visa** documentation, **self-sponsored insurance**, and **Ejari in your own name** before banking. Cash buffer toward the **upper end** (AED 25K+ singles) because no first salary date anchors cash flow. Co-working lease is not Ejari: you still need residential tenancy for visa and DEWA unless your visa route explicitly allows otherwise.

## What should you pack vs buy locally?

| Bring | Buy in Dubai |
| --- | --- |
| Prescription meds + doctor letter | Furniture, appliances |
| Laptops, phones, adapters | Bulky kitchen gear |
| Key documents (attested copies) | Car after licence sorted |
| Small sentimental items | Most clothing (malls active) |

Avoid shipping **large furniture** unless sentimental; IKEA, Home Centre, and second-hand marketplaces are mature.

## Who owns each task: PRO vs you?

| PRO typically handles | You personally handle |
| --- | --- |
| Entry permit, visa stamping | School tours and deposits |
| Medical appointment booking (some employers) | Community viewings and lease negotiation |
| Labour contract (employment) | Ejari confirmation with landlord |
| Dependent visa submission (sometimes) | Bank interview and cheque book |

Write PRO scope into email so gaps do not appear in week two when DEWA is blocked for missing Ejari.

## What should you settle in months 3 to 6?

| Task | Done |
| --- | --- |
| Review banking and credit products | ☐ |
| Optimise insurance (health, home, car) | ☐ |
| Plan home-country tax reporting if applicable | ☐ |
| Evaluate housing upgrade if commute failed | ☐ |

Free zone vs mainland employment affects spouse work permissions; investor visa holders focus on **ICP renewal** and **property value maintenance** for Golden Visa.

## Invest Gulf: relocation sequencing for Gulf buyers

Invest Gulf relocation packs fail most often when **Ejari date** slips past **school registration deadline** or **DEWA** application. Build a single Gantt with PRO dates, landlord Ejari appointment, and school deposit deadline on one page. Property buyers should run **visa track** and **purchase track** on separate lines until DLD registration completes, then merge for EID and banking.
