## What should you verify before an off-plan Select Group purchase?

Off-plan Select Group purchases typically require the same RERA checks as any Dubai forward sale, and Invest Gulf verifies Trakheesi, escrow, and prior handover slips of 6 to 18 months on older phases before foreign buyers sign an SPA on a new pipeline tower across this market corridor.

Treat any new pipeline phase as a standalone underwriting file.

Verify before you sign an SPA:
1. Last Select Group handover on a comparable tower: SPA date vs key collection
2. Construction site visit: facade, MEP, amenity completion
3. Broker months-on-market for completed Select Group units in the target building
4. Escrow account letter and Trakheesi permit in writing

Main risks on Select Group stock typically include yield compression at 5 to 7% gross, waterfront service charges of AED 18 to 28 per sqft, older Promenade maintenance reserves, and thinner off-plan pipeline, which Invest Gulf flags for foreign buyers before any deposit on the developer in this market.
